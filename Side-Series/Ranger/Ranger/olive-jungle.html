Obstacles

  • Several Jungle Trees require Tackle x1 to clear, which can be found on nearby Phanpy. All trees in Olive Jungle contain either Silcoon or Slakoth.
  • A Dead Tree requires Tackle x3 to clear, which can be found on Heracross.
  • A Vine requires Soak x1 to clear, which can be found on Lotad. It leads to wild Grovyle and Lombre.
  • Undergrowth requires Cut x1 to clear, which can be found on Treecko, Grovyle, and Gligar. It leads to wild Lombre.
  • A Metal Fence requires Cut x2 to clear, which can be found on nearby Grovyle.
